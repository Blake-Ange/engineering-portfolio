# Enterprise API & Systems Engineering

**Category:** Backend Engineering / Systems Integration

**Technologies:** Java, REST APIs, PostgreSQL, OAuth 2.0, JWT, JavaScript, Linux

## Overview

Designed and developed enterprise software integrations connecting independent business applications, external services, and internal processing workflows.

## Engineering Contributions

- Architected backend services and API interfaces for third-party software integrations.
- Designed relational database schemas supporting application workflows and integration data.
- Implemented secure authentication and authorization mechanisms for cross-platform communication.
- Developed application components enabling data exchange and workflow automation.
- Conducted integration testing, troubleshooting, and deployment preparation.
- Coordinated technical requirements with external engineering teams and business stakeholders.

## Results

- Delivered production integrations alongside additional beta-stage implementations.
- Reduced manual interaction between disconnected software platforms.
- Established modular components supporting continued integration development.
