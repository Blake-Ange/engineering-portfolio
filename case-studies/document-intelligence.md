# Document Intelligence Pipeline

**Category:** Software Engineering / Document Automation

**Technologies:** Python, PDF Processing, Data Extraction, JSON, Excel

## Overview

Developed a Python application that transforms complex architectural PDF documents into structured, usable data.

## Engineering Contributions

- Designed document-processing and structured data extraction workflows.
- Implemented validation and data reconciliation.
- Developed automated JSON and Excel exports.

## Results

Demonstrated processing of 17 architectural pages, identifying 36 apartment instances in approximately 1.5 seconds.

## Source Availability

The application source code and underlying implementation are maintained privately.
